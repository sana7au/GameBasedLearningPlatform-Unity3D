# SortingAlgorithms-Unity3D

A Unity-based educational game that teaches **Sorting Algorithms** through interactive 3D cubes. The project allows players to learn and practice **Bubble Sort, Selection Sort, and Insertion Sort** by manually performing sorting operations.

This was one of my first Unity projects, where I learned the basics of Unity by building the project myself. It helped me understand **Scenes, Panels, Canvas, Buttons, 3D objects, C# scripts, UI elements**, and how to connect code with different Unity components.

## 📚 Algorithms Covered

### Bubble Sort
Players learn Bubble Sort by comparing and swapping adjacent cubes until the numbers are arranged in the correct order.

### Selection Sort
Players find the smallest element from the unsorted part and move it to its correct position.

### Insertion Sort
Players place each element into its correct position within the already sorted part of the array.

## 🎯 Project Purpose

The main purpose of this project was to create an interactive way to learn sorting algorithms instead of only studying them theoretically.

Players can interact with the 3D cubes and perform the sorting operations themselves, making the learning process more practical and engaging.
